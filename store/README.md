## ビルド

```powershell
cd <このリポジトリのフォルダ>
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat test assembleRelease
New-Item -ItemType Directory -Force dist | Out-Null
Copy-Item app\build\outputs\apk\release\app-release.apk dist\cycleroutelogger-0.12.0-release.apk -Force

# 署名の確認（証明書の SHA-256 が下の「鍵の管理」の値であること）
& "$env:JAVA_HOME\bin\java.exe" -jar "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\lib\apksigner.jar" verify --print-certs dist\cycleroutelogger-0.11.0-release.apk
# Maps キーが入っているか（何も出なければキー入り。値そのものは表示しない）
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\aapt.exe" dump xmltree dist\cycleroutelogger-0.11.0-release.apk AndroidManifest.xml | Select-String "PLACEHOLDER"
```

**`local.properties` に `MAPS_API_KEY=...` が無いと、プレースホルダ入りの APK ができて地図が灰色になる。**
logcat の Maps SDK のエラーにはキーが出るので、そのまま貼り付けない。

## Google Cloud の API キー制限（配布の前提・ユーザー作業）

`local.properties` の `MAPS_API_KEY` は gps_camera / trip_planner と同じキーをコピーしてある。
キーには **Android アプリ制限（パッケージ名 + 署名 SHA-1）** が掛かっているので、このアプリの 2 行を足さないと
地図は灰色のまま（2026-10-11 のエミュレータ確認で `Authorization failure` を確認。地図以外は動く）。

1. Google Cloud Console →「API とサービス」→「認証情報」→ 使っている API キーを開く。
2. **アプリケーションの制限**（Android アプリ）に次の 2 行を追加する。

   | パッケージ名 | SHA-1 証明書フィンガープリント | 用途 |
   | --- | --- | --- |
   | `jp.kjtr.cycleroutelogger` | `4C:A3:6C:59:E1:D9:01:DF:33:ED:0C:AC:7F:40:39:1D:A3:92:BC:88` | release（`release.jks` / alias `cycleroutelogger`） |
   | `jp.kjtr.cycleroutelogger` | `E8:23:4F:83:8C:8A:94:8A:D1:82:60:CE:68:6B:F4:AC:DA:64:2F:CF` | debug（`~/.android/debug.keystore`。他アプリと共通） |

   SHA-1 を取り直すときは `keytool -list -v -keystore release.jks -alias cycleroutelogger`（パスワードは `keystore.properties`）。
3. **API の制限**: Maps SDK for Android のみ（既存のまま）。
4. 保存後、反映まで数分かかることがある。実機（またはエミュレータ）で地図タイル・ルートの線・経由地のマーカーが出ることを確かめる。

- Google のロゴと帰属表示は SDK が地図の左下に出す。**消したり UI で覆ったりしない**（走行画面は `contentPadding` で下のパネルを避けている）。
- 料金: Maps SDK for Android の地図表示は無料（回数無制限）だが、プロジェクトに請求先アカウントが要る。予算アラートを推奨。
- キーをアプリごとに分けるなら、新しいキーに上の 2 行と API 制限を設定し、`local.properties` を差し替えてビルドし直す。

## 鍵の管理（最重要）

`release.jks` と `keystore.properties` は **git 管理外**。失うと更新版を配れなくなる。
**PC とは別の場所（クラウドストレージや外付けなど）に必ずコピーを取ること。**
Maps キーの Android 制限も release の SHA-1 に紐付くので、鍵を作り直すとキー側の登録もやり直しになる。

| 項目 | 値 |
| --- | --- |
| alias | `cycleroutelogger` |
| 形式 | PKCS12、RSA 2048、有効期間 10000 日（2026-10-11 作成） |
| 証明書 SHA-1 | `4C:A3:6C:59:E1:D9:01:DF:33:ED:0C:AC:7F:40:39:1D:A3:92:BC:88` |
| 証明書 SHA-256 | `5E:CB:A9:EF:58:46:36:FA:B9:53:99:A6:72:2D:1D:E7:E3:0F:C7:96:B5:7B:20:E0:23:2B:57:4E:28:E8:6E:39` |

## 掲載文で触れておくこと

- **権限**: 位置（表示と記録。「アプリの使用中のみ」で可。裏に回しても記録は続く）、
  フォアグラウンドサービス（記録中は通知）、通知、インターネット（地図・利用者が指定した URL からの GPX 取得）、WAKE_LOCK・振動。
  任意: 位置の「常に許可」（記録中にアプリが落とされたときの自動再開だけに使う）、電池の最適化から外す確認。
  カメラ（0.3.0〜。走行中の写真。撮影ボタンを初めて押したとき）、ストレージの書き込み（Android 9 以下だけ。写真をライブラリに保存）。
- **通信先**: Google マップ、利用者が指定した URL（QR コードで読んだものを含む）、更新の確認の GitHub（raw.githubusercontent.com、0.4.0〜。設定で OFF にできる）、場所名の検索の Nominatim（nominatim.openstreetmap.org、0.6.0〜。検索ボタンを押したときだけ）、オンラインランキングのサーバ（taisen-game.com、0.12.0〜。設定で参加した人だけ・既定 OFF）だけ。
  QR の読み取りは Google Play 開発者サービスの Code Scanner（初回に読み取り機能をダウンロードすることがある）。記録・プランは送らない（書き出し・共有は利用者の操作だけ）。
  0.9.0〜 設定「測位の方式」で「Google の融合測位」を選んだときは、位置の計算に Google Play 開発者サービスを使う（既定は端末の GPS。Play 開発者サービスが端末の設定に応じて情報の一部を Google に送ることがある）。
- **Play に出すなら**: ACCESS_BACKGROUND_LOCATION は位置情報の権限の申告（動画つき）と審査が要る。REQUEST_IGNORE_BATTERY_OPTIMIZATIONS は
  Play では許可される用途が限られる（使うなら申告、だめなら設定画面を開くだけにする）。どちらも外しても記録はできる。
- **安全**: 走行中に操作・注視しない。ホルダーに固定。GPS は目安。
- **自動更新なし**（APK 直接配布）。0.4.0〜 は新しい版が出たらホームの帯で知らせる（ダウンロードはブラウザ）。更新は同じ鍵で versionCode を上げる。アンインストールすると記録は消える（先にバックアップ）。
